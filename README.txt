# 🐻 Bear Study - Complete Website

Cấu trúc:
- index.html   - giao diện chính
- styles.css   - giao diện pastel xanh dương + gấu nâu
- script.js    - từ vựng, flashcard, quiz, typing, tài khoản và tiến trình
- README.txt   - hướng dẫn sử dụng

Cách chạy:
1. Giải nén thư mục.
2. Giữ 3 file HTML/CSS/JS trong cùng một thư mục.
3. Mở index.html bằng trình duyệt.

Tài khoản:
Hệ thống đăng ký/đăng nhập hiện dùng LocalStorage. Mỗi tài khoản có tiến trình riêng trên trình duyệt hiện tại, gồm từ đã học, yêu thích, từ cần ôn, XP và chế độ giao diện.

Lưu ý:
Đây là hệ thống tài khoản demo phía trình duyệt, phù hợp cho dự án HTML/CSS/JavaScript. Không dùng để lưu mật khẩu hoặc dữ liệu nhạy cảm trên website production.
